# ПРОГНОЗИРОВАНИЕ ПОЧАСОВОГО СПРОСА НА АРЕНДУ ВЕЛОСИПЕДОВ

## Описание проекта

Компания **BikeSouth** развивает городской велопрокат на юге России. Задача -- 
разработать модель машинного обучения, которая предсказывает количество 
велосипедов, арендованных  в каждый конкретный час, на основе погодных 
и календарных характеристик.

## Цель

- Повысить точность прогнозов почасового спроса.
- Оптимизировать логистику распределения велосипедов.
- Улучшить клиентский опыт (избегать простоев и дефицита).

## Данные

Два датасета:
- `ds_s14_train_data.csv` - обучающая выборка (7008 строк).
- `ds_s14_test_data.csv` - тестовая выборка (1752 строки).

Признаки:
- **Температура** (°С)
- **Влажность** (%)
- **Скорость ветра** (м/с)
- **Видимость** (10м)
- **Точка росы** (°С)
- **Солнечная радиация** (МДж/м2)
- **Осадки (дождь)** (мм)
- **Осадки (снег)** (см)
- **Сезон** (Winter, Spring, Summer, Autumn)
- **Праздник** (Holiday / No Holiday)
- **Функционирующий день** (Yes / No)
- **Время суток** (Night, Morning, Daytime, Evening, Late Evening)

## Результаты

4. **Функционирование** (9.6% важности).
